=>Python Web Scraper

This project demonstrates a Python-based web scraping workflow.

=>Features
- Scrapes website data using Requests and BeautifulSoup
- Extracts structured information
- Stores data in CSV format
- Simple and scalable scraping pipeline

=>Technologies Used
- Python
- BeautifulSoup
- Requests
- CSV

=>Use Case
Useful for extracting datasets from websites for analysis, AI training, or automation workflows.
